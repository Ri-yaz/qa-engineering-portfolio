# NEPSE Edge – Web Application Quality Assurance Testing

## Project Overview

This repository documents my independent Quality Assurance (QA) testing of **[NEPSE Edge](https://nepseedge.com/)**, a Nepal Stock Exchange (NEPSE)-focused trading and research platform.

NEPSE Edge provides traders and investors with tools to monitor their portfolios, maintain trading journals, develop and evaluate trading strategies, perform historical backtesting, screen stocks, and analyze market opportunities.

The objective of this project is to evaluate the application's functionality, usability, navigation, and overall user experience by identifying potential defects, executing test scenarios, documenting test results, and preparing structured bug reports.

This project is part of my practical learning and hands-on experience in Software Quality Assurance.

## Application Features

The application provides the following major features:

- **Portfolio Tracking:** Monitor stock holdings, portfolio allocation, returns, and performance.
- **Trading Journal:** Record trades, trading decisions, mistakes, and performance.
- **Strategy Management:** Create, manage, and evaluate trading strategies.
- **Backtesting:** Test trading strategies against historical market data.
- **Stock Screener:** Filter stocks using technical and fundamental parameters.
- **Watchlist & Notes:** Track selected stocks and maintain research notes.
- **Technical Analysis:** Analyze stock charts and market trends.
- **AI Insights:** Explore trading-related insights using available portfolio and market information.
- **Community:** Share trading ideas and interact with other market participants.

## QA Testing Objectives

1. Verify that application functionalities work according to their expected behavior.
2. Identify functional defects and inconsistencies in the application.
3. Validate navigation links, buttons, menus, and interactive elements.
4. Evaluate UI consistency, responsiveness, and usability.
5. Verify input fields, form validations, and error handling.
6. Identify issues affecting user experience and application reliability.
7. Document defects with clear reproduction steps and supporting evidence.
8. Prepare test execution results and summarize the overall testing outcome.

## Testing Methodology

The testing process follows these steps:

1. **Application Understanding:** Explore the application and understand its features and workflows.
2. **Test Scenario Design:** Identify testable functionalities and prepare test scenarios.
3. **Test Case Preparation:** Develop positive, negative, and boundary test cases.
4. **Test Execution:** Execute test cases and compare actual results against expected results.
5. **Defect Identification:** Identify and reproduce application defects.
6. **Bug Reporting:** Document defects with steps to reproduce, severity, priority, and evidence.
7. **Test Summary:** Evaluate test execution results and summarize identified issues.
